# app-super-info
Aplicativo de Informações sobre o Ensino Superior na Bahia

## Sobre o Projeto
Este aplicativo tem como objetivo centralizar e facilitar o acesso a informações sobre o ensino superior na Bahia, incluindo instituições de ensino, processos seletivos, atividades acadêmicas, direitos estudantis e orientações para estudantes.

CD01-Comunicação de Dados  

## Campo de Aplicação
